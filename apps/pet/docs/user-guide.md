# 설치와 사용

## 처음 준비하기

Windows 설치 파일을 실행하고 설치 화면의 안내를 따릅니다. 일반 사용자는 Git, Bun, Rust나 개발용 터미널을 따로 준비할 필요가 없습니다. '이 컴퓨터'를 고르면 처음 실행 때 검색용 모델 4개(글 검색 bge-m3, 결과 정렬 bge-reranker-v2-m3, 이미지 검색 SigLIP2, 한국어 형태소 분석 Kiwi, 합계 약 1.7GB)를 받습니다. 인터넷 연결과 약 2.7GB의 여유 공간(모델 + DB·임시 파일 여유 1GB)이 필요합니다. 질문에 답하는 AI(Ollama, LM Studio 등)는 바라가 받지 않으며, 따로 설치해 두면 연결만 합니다.

처음 실행하면 **바라 시작하기**가 네 단계로 열립니다.

1. **기억을 어디에 보관할까요?** 아래 표의 세 가지 중 하나를 고르고 준비합니다.
2. **어떤 AI를 쓸까요?** 이 PC의 AI를 찾아 고릅니다(아래 "AI 연결과 기억 정리"). 건너뛰어도 기억 저장·검색은 쓸 수 있습니다.
3. **연결을 확인할게요.** 기억 저장소, 답변 AI, 기억 정리 AI를 각각 확인합니다. 고르지 않은 AI는 실패가 아니라 "나중에 연결"로 표시됩니다.
4. **바라를 어떻게 둘까요?** "펫으로 보기" 또는 "트레이로만 사용"과 로그인 시 자동 실행을 고르고 **시작하기**를 누릅니다.

중간에 창을 닫거나 바라를 종료해도 다음에 실행하면 멈춘 단계부터 이어집니다. 준비가 끝난 뒤에는 트레이의 **설정**에서 같은 항목을 바꿀 수 있습니다.

| 선택 | 준비하는 것 |
|---|---|
| 이 컴퓨터 | 이 PC에 펫과 메모리 서버를 준비합니다. |
| 내 외부 서버 | 펫은 PC에 두고, 이미 생성된 Ubuntu 서버에 메모리 서버를 설치합니다. |
| 기존 바라 | 서버를 다시 설치하지 않고 기존 기억에 연결합니다. |

외부 서버를 새로 만들거나 클라우드 계정에 가입하는 기능은 포함하지 않습니다. 원격 설치에는 서버 주소, 접속 계정, SSH 키와 설치 권한이 필요합니다. 자동 설치는 root 또는 비밀번호 입력 없이 관리자 명령을 실행할 수 있는 계정을 대상으로 합니다.

서버 연결 확인에서 표시되는 지문은 해당 서버의 공개키를 식별합니다. 서버에서 안내받은 지문과 대조해 확인합니다. 지문이 바뀌면 자동으로 계속 연결하지 않습니다. 암호가 걸린 SSH 키는 운영체제의 SSH 에이전트에서 먼저 사용할 수 있는 상태여야 합니다.

기존 바라에는 연결 토큰 또는 인증정보가 포함된 대시보드 접속 링크를 입력할 수 있습니다. 관리자 링크가 있으면 펫 전용 연결을 등록합니다. 연결 토큰이 없으면 기존 대시보드에서 펫의 연결 요청을 승인합니다. 기존 서버도 펫 연결을 지원하는 바라 버전이어야 합니다.

펫을 오른쪽 클릭해 창을 열고 상단의 **대시보드 열기**를 누르면, 저장된 관리자 인증정보로 기본 브라우저에서 대시보드를 엽니다. 관리자 링크를 아직 등록하지 않았다면 연결 정보에 인증정보가 포함된 대시보드 링크를 한 번 입력합니다. 이후에는 주소에 토큰을 붙일 필요가 없습니다.

이 PC에서 바라 서버가 이미 실행 중이면 '이 컴퓨터'는 새 저장소를 만들지 않고 멈춥니다. 안내에 표시된 주소로 '기존 바라'를 선택해 그 서버에 연결합니다.

외부 서버에 바라가 이미 설치되어 있으면 '내 외부 서버'는 새로 설치하지 않고 멈춥니다. 바라 서비스가 멈춰 있거나 자동 시작이 꺼져 있어도 같습니다. 이때는 '기존 바라'에서 SSH 연결을 켜고 그 서버에 연결합니다.

펫이 설치한 서버에 '서버에 설치하고 연결'을 다시 누르면 먼저 서버의 실제 설치 상태를 확인합니다. 정상이면 서버 파일을 바꾸지 않고 연결만 합니다. 서비스가 멈춰 있으면 다시 시작하고 자동 시작을 켭니다. 설치가 중간에 끊겼으면 설치 단계를 다시 실행해 마무리합니다. 어느 경우든 서버의 기억 데이터와 인증 정보는 그대로 씁니다. 이미 연결한 서버가 있으면 같은 서버(주소, 접속 포트, 계정이 같음)를 복구하는 경우에만 진행합니다.

## 가볍게 입력하기

펫을 누르면 작은 입력줄이 열립니다. 내용을 적고 Enter 또는 오른쪽 전송 버튼으로 보냅니다. Shift+Enter는 줄바꿈입니다. 왼쪽 전환 버튼으로 같은 글을 입력 또는 질문으로 보낼 수 있습니다.

펫을 한 번 더 누르거나 입력창 바깥을 누르면 입력창이 닫힙니다. Escape로도 닫을 수 있습니다. 보내기 전 작성하던 내용은 남아 있어, 펫을 다시 누르면 이어서 쓸 수 있습니다.

저장 결과는 말풍선으로 알려줍니다. 말풍선을 누르면 관련 기억을 엽니다. 누르지 않으면 말풍선만 접히고 저장된 기억은 남습니다. 분류가 가능한 AI를 연결하면 저장이 확인된 뒤 분류를 보조합니다. 원문은 보존하며 분류는 수정할 수 있습니다.

분류는 **아이디어, 결정, 궁금한 것, 취향·선호, 할 일, 정보·경험**입니다. 컴퓨터 사양·현재 사용 환경·참고 지식·이미 겪은 일은 **정보·경험**에 해당합니다. 예를 들어 "작업 컴퓨터의 그래픽카드는 4080S"는 정보·경험이고, "4080S가 더 좋다"는 취향·선호입니다. "어제 업데이트했다"는 정보·경험, "내일까지 업데이트해야 한다"는 할 일입니다. 태그는 주제를 나타내며 분류를 지정하지 않습니다. 뜻이 모호하거나 문맥이 부족하면 AI는 분류를 보류합니다.

연결한 서버가 아직 정보·경험을 지원하지 않으면 자동 분류는 해당 기록의 분류를 보류합니다. 정보·경험으로 직접 저장하거나 수정하면 서버 업데이트가 필요하다는 안내가 나옵니다. 서버도 이 분류를 지원하는 버전으로 업데이트한 뒤 다시 시도하세요.

저장이 확실히 거절된 경우 내용을 그대로 두고 다시 시도할 수 있습니다. 연결이 끊겨 저장 여부가 불확실하면 전송한 내용을 보관합니다. 먼저 저장 여부를 확인하거나 검색으로 찾아보세요. 확인 없이 같은 내용을 자동으로 다시 보내지는 않습니다.

## 질문과 원문 보기

펫을 누르고 입력줄 왼쪽에서 질문을 선택해 평소 말투로 묻습니다. 관련 기억을 검색하고 연결된 AI가 답변합니다. AI가 없을 때도 검색한 기억을 보여줍니다. 질문 자체는 새 기억으로 자동 저장하지 않습니다.

답은 먼저 짧은 말풍선으로 표시합니다. 누르면 자세한 답과 근거 기억을 엽니다. 최근 답변은 별도로 다시 열 수 있습니다. 근거 기억을 누르면 전체 원문을 읽거나 수정할 수 있습니다. 기존 태그는 본문 수정과 분리해서 보존합니다.

## AI 연결과 기억 정리

연결과 설정의 **답변 AI와 기억 정리**에서 **이 PC의 AI 찾기**를 누르면 이 PC에서 실행 중인 Ollama, LM Studio, Jan, llama.cpp 서버를 찾아 목록으로 보여줍니다. 하나를 누르면 질문에 답할 AI로 고르고, 모델은 목록에서 고릅니다. 모델이 하나뿐이면 자동으로 골라집니다. 찾지 못했거나 다른 주소를 쓰려면 **고급 설정**에서 주소와 모델 이름을 직접 입력하고 **이 주소의 모델 불러오기**를 누릅니다. AI가 없어도 기억 저장·검색은 쓸 수 있습니다.

같은 검색에서 Claude Code와 Codex가 이 PC에 설치되어 있는지도 확인해 기억 정리 AI 목록에 표시합니다. 로그인 여부는 저장한 뒤 연결을 확인할 때 검사합니다.

**AI 설정 저장**을 누르면 답변 AI와 기억 정리 설정을 함께 저장한 뒤 각각 실제로 쓸 수 있는지 확인합니다. 답변 AI 상태와 기억 정리 AI 상태가 따로 표시되며, "저장했고 사용할 수 있어요"와 "저장했지만 아직 쓸 수 없어요"(설치 안 됨, 로그인 필요, 모델 없음, 연결 실패 등 원인 포함)를 구분합니다. 값을 바꾸면 아직 저장하지 않았다는 안내가 나옵니다.

기억 정리에는 로컬 AI 또는 설치·로그인된 Codex CLI, Claude Code를 사용할 수 있습니다. 데스크탑 AI 앱이 설치되어 있다는 사실만으로 모든 연동이 가능한 것은 아닙니다. 지원하는 실행 프로그램과 인증 상태를 확인합니다.

정리 AI가 만든 내용은 제안으로 등록합니다. 변경할 내용은 검토 화면에서 확인합니다. AI에 관리자 토큰이나 자기 제안을 승인할 권한을 주지 않습니다.

## 자동 실행과 데이터

연결과 설정에서 로그인 시 자동 실행을 켜거나 끌 수 있습니다.

작업 표시줄 오른쪽의 바라 아이콘을 왼쪽이나 오른쪽으로 누르면 메뉴가 열립니다. 아이콘이 보이지 않으면 작업 표시줄의 숨겨진 아이콘(^)을 확인하세요.

- **입력**·**검색**: 작은 입력창을 기록 또는 질문 상태로 엽니다. 이미 열려 있으면 닫지 않고 그 창으로 이동합니다. 펫을 누를 때는 지금처럼 입력창이 열리고 닫힙니다.
- **대시보드**: 브라우저에서 현재 연결한 바라의 대시보드를 엽니다.
- **설정**: 연결과 설정 창을 엽니다. 창은 펫 옆(보통 왼쪽, 자리가 없으면 위나 오른쪽)에 열리고, 펫을 숨긴 동안에는 트레이 아이콘 근처에 열립니다. 이미 열려 있으면 옮기지 않고 그 창으로 이동합니다.
- **최근 결과**: 마지막으로 본 저장 결과나 답변을 말풍선으로 다시 보여줍니다.
- **펫 숨기기**·**펫 보이기**: 캐릭터만 숨기거나 다시 보입니다. 숨겨도 기억 저장·검색은 그대로 쓸 수 있고, 작성 중인 입력도 지워지지 않습니다. 고른 상태는 다음에 실행할 때도 이어집니다.
- **바라 종료**: 바라와 이 PC에서 함께 실행한 메모리 서버를 종료합니다.

메뉴 명령이 실패하면 원인을 말풍선으로 알려줍니다.

펫을 숨긴 동안에는 입력창과 말풍선이 트레이 아이콘 근처에 나타납니다. 직접 저장하거나 물어본 결과만 말풍선으로 보여주고, 시작할 때의 연결 확인처럼 바라가 스스로 한 일의 결과는 말풍선을 띄우지 않습니다. 그런 결과가 있으면 트레이 메뉴 첫 줄이 "확인할 결과 있음"으로 바뀌니 **최근 결과**로 확인하세요.

기본 로컬 데이터는 `%LOCALAPPDATA%\Bara\Pet` 아래에 둡니다. 앱 실행 파일과 메모리 DB·모델·설정을 분리합니다. 기본 설치 위치에서는 앱 제거가 메모리 데이터 삭제를 뜻하지 않습니다. 중요한 기억은 바라의 백업 기능으로 별도 보관하세요.

바라를 제거하면 첫 화면에 **검색용 AI 모델도 삭제 (약 1.7GB, 기억 데이터는 남음)** 선택 칸이 나옵니다. 처음에는 선택되어 있지 않습니다. 선택하면 이 PC에서 기억 검색에 쓰려고 바라가 내려받은 모델 폴더 두 개(`%LOCALAPPDATA%\Bara\Pet\memory\models\hf-cache`, `...\models\kiwi-model`)만 함께 지웁니다. 데이터 폴더를 환경 변수 `BARA_PET_DATA_DIR` 로 옮겨 두었다면 그 폴더 아래의 같은 두 폴더를 지웁니다. 기억 DB·설정·로그인 정보·AI 키·백업은 지우지 않고, Ollama나 LM Studio의 모델도 건드리지 않습니다. 다시 설치하면 모델을 처음부터 다시 내려받습니다. 바라가 아직 실행 중이거나 다른 프로그램이 모델 파일을 쓰고 있어 다 지우지 못하면 제거 기록과 알림 창에 지우지 못한 폴더를 알려 주니, 바라를 모두 끈 뒤 그 폴더를 직접 지우세요. 새 버전 설치 중에 이전 버전을 먼저 제거하는 경우(업데이트·다시 설치)나 조용히 제거하는 경우(`/S`, `/P`)에는 이 칸이 나오지 않고 모델도 지우지 않습니다. 다음 확인 화면의 **애플리케이션 데이터 삭제하기**는 설치 프로그램이 기본으로 넣는 항목으로, `%APPDATA%`·`%LOCALAPPDATA%` 의 `app.bara.pet` 폴더만 지웁니다. 바라는 기억·모델·설정·화면 캐시를 모두 `Bara\Pet` 아래에 두므로 이 항목은 그것들을 지우지 않습니다.

연결과 설정의 **백업**에서 **백업 만들기**를 누르면 이 PC에 저장한 기억과 첨부를 글 형식으로 내보냅니다. 바라를 켜 둔 채로 만들 수 있고, 문서 폴더의 `Bara 백업` 안에 `bara-backup-날짜-시각` 폴더로 저장됩니다. 바라를 지워도 이 폴더는 남습니다. 설정·로그인 정보·AI 키는 들어가지 않습니다. 시작하기 전에 남은 공간을 확인하고, 만드는 중에는 **중단**할 수 있습니다. 끝나면 **폴더 열기**로 위치를 열 수 있습니다. 다른 서버에 둔 기억은 여기서 백업하지 않습니다.

같은 곳의 **백업에서 되살리기**를 누르면 바라가 아는 백업 — 직접 만든 백업(`Bara 백업`의 `bara-backup-…`)과 업데이트 전에 바라가 자동으로 만든 백업 — 이 만든 날짜, 종류, 기억·첨부 수와 함께 목록으로 나옵니다. 하나를 고르고 확인하면 이 PC의 기억을 그 백업 시점으로 되살립니다. 먼저 백업이 온전한지 확인하고 남은 공간을 검사하며, 그동안은 아무것도 바뀌지 않습니다. 되살리는 동안에는 바라 기억 서버가 멈춰서 기억을 저장하거나 물어볼 수 없습니다(입력한 내용은 저장되지 않고 입력창에 남습니다). 검색 색인을 다시 계산하므로 기억이 많으면 오래 걸리고, 검색 모델이 없으면 먼저 내려받습니다. 진행 단계와 지난 시간이 보이고, 기억을 바꾸는 단계 전까지는 **중단**할 수 있습니다. 중단하거나 실패하면 지금 기억은 그대로이고 서버가 다시 시작되며, 같은 백업을 다시 고르면 **이어서 되살리기**로 멈춘 곳부터 계속합니다. 끝나면 되살린 기억·첨부 수와 함께, 그전까지 쓰던 기억을 옮겨 둔 폴더(`%LOCALAPPDATA%\Bara\Pet\memory\before-restore-날짜-시각`)를 알려 줍니다. 이 폴더는 자동으로 지우지 않으니, 되살린 기억이 맞는지 확인한 뒤 직접 지우세요. 설정·로그인 정보·AI 키는 그대로입니다. 되살리는 도중에 PC가 꺼져도 다음에 바라를 켤 때 기억을 바꾸던 일을 마저 끝내거나 원래대로 되돌린 뒤에 서버를 시작합니다. 다른 서버에 연결해 둔 동안에는 이 버튼을 쓸 수 없습니다.

PC를 끄면 PC의 펫·로컬 서버·로컬 AI 작업은 멈춥니다. 별도 서버에 설치한 메모리 서비스는 PC와 독립적으로 동작합니다.
