- `src/ui/notebook.test.ts`, `tests/native-config.test.ts`: 빠른 전환, 동일 화면 입력 유지, 동작 줄이기와 애니메이션 부재, 권한 회귀 검사.

## 사용자 피드백 반영

사용자가 Windows 테스트 창에서 바라 이름을 잡은 이동, 최소화, X로 숨기기를 확인했다. 첫 회전 시안은 어색하다는 피드백을 받아 별도 빈 종이 오버레이를 제거했다. 최종 전환은 실제 새 내용이 8px 올라와 자리 잡는 200ms 효과이며 페이지 영역 안으로 제한한다.

하단 버튼·상태 안내가 종이 가장자리 밖으로 내려간다는 피드백은 종이 이미지의 가장자리/그림자 높이에 맞춘 `max(48px, 8.5vh)` 하단 안전 여백으로 수정했다. 좁은 화면 규칙이 이를 덮어쓰지 않는다. 상태 안내가 나타나면 본문 스크롤 높이를 줄이고 하단 버튼 위치는 유지한다.

## 검증 환경과 한계

Windows 테스트 앱은 별도 `.omx/notebook-native/data`와 WebView 프로필·백업 경로를 사용했다. 사용자 DB·토큰·AI 키·자동 실행 설정을 사용하거나 바꾸지 않았다. 새 서버 설치나 모델 다운로드는 실행하지 않았다. 기존 설치판을 교체하지 않았다.

브라우저 시각 자료는 `.omx/notebook-qa/`에 저장했다. 생성 원본은 이 채팅의 generated_images에 보존하고 제품에서 쓰는 복사본은 저장소에 넣었다. 투명 영역의 OS 마우스 클릭 통과는 구현하지 않았다. 다중 모니터/DPI 전체 조합 및 실제 설치기 업데이트는 이번 검증 범위가 아니다.
