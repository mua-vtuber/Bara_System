# 스프링 메모장 팝업 디자인

사용자가 승인한 이미지 시안을 기존 Bara Pet 팝업에 적용한다. 시안은 이 채팅에서 생성한 세로 스프링 메모장으로, 종이 질감과 위쪽 금속 스프링, 왼쪽 빨강·파랑·노랑·초록 인덱스가 특징이다. 인덱스를 누르면 종이가 위로 넘어가거나 뒤 페이지가 앞으로 드러나는 짧은 전환을 추가한다. 애니메이션보다 사용성이 우선이며 기능과 데이터 계약은 유지한다.

## 범위

- 메인 팝업의 기존 방금 받은 답, 저장 확인, 기억 정리, 연결과 설정 화면을 같은 메모장 안에 배치한다.
- 왼쪽 인덱스 메뉴 4개와 대시보드, 마지막 답변, 기억 남기기, 질문하기 동작을 보존한다.
- 설정의 연결 방식 3개, AI 선택, 자동 실행, 백업/복원을 유지한다. 긴 내용은 종이 안에서 스크롤한다.
- 종이·스프링·탭 표면에 이미지 생성으로 만든 PNG 자산을 사용한다. 글자와 컨트롤은 접근 가능한 실제 DOM이다. 생성 이미지에 글자와 버튼을 굽지 않는다. SVG로 시안을 대체하지 않는다.
- 첫 280ms 회전 시안은 사용자 확인에서 어색하다는 피드백을 받았다. 본문 위에 별도 사각 종이가 뒤집히는 효과를 제거하고, 실제 새 페이지 내용이 짧게 올라와 자리 잡는 약 200ms 전환으로 줄인다. 스프링/메뉴는 고정한다. 연속 클릭, 동일 화면 요청, 입력 중 설정 재열기, 초기 설치, 비동기 응답, 동작 줄이기를 처리한다. 애니메이션은 서비스 요청이나 화면 렌더를 지연하지 않는다.
- 기존 빠른 입력창, 말풍선, 펫 그림과 서비스/DB 동작은 변경하지 않는다. 기존 자격 증명·운영 데이터는 사용하지 않는다.
- 480×700 기본 창과 작은/큰 창에서 인덱스 및 동작을 잃지 않는다. 기존 네이티브 창의 이동/닫기 동작을 보존한다. 시안의 닫기 버튼을 가짜로 만들지 않는다.
- 사용자 추가 요청: 메인 창도 투명·무테로 바꾸어 배경의 네모난 창을 없앤다. 메모장 헤더를 드래그 영역으로 쓰고 실제 최소화·닫기(기존 창 닫힘 정책) 동작을 제공한다. 투명 여백과 종이 그림자, 화면 경계 배치를 검사한다. 무테에서도 기존 크기 조절 기능을 가능한 한 보존한다.
- 새 의존성 없음. 사용자 문구는 messages.ts에서 관리한다.
- 실제 창 피드백: 사용자 확인으로 바라 이름을 잡은 이동, 최소화, X로 창 숨기기가 동작한다. 하단 버튼과 상태 안내가 종이의 겹친 가장자리로 내려가지 않도록 창 높이에 비례한 종이 안전 여백을 확보한다.

## 확인 기준

1. 브라우저에서 실제 빌드된 팝업의 메모장 재질, 한글 가독성, 탭 위치를 시안과 비교한다.
2. 모든 메뉴, 키보드 초점, 스크롤, 연결 방식 전환, AI 항목 및 백업 버튼을 확인한다. 실제 저장/서버 작업은 호출하지 않는다.
3. 화면을 빠르게 전환해도 마지막 선택이 표시되고 유령 페이지/중복 폼/클릭 차단이 남지 않는다. 동작 줄이기에서는 전환 없이 화면이 바뀐다.
4. 실제 동작 로직을 바꾼 부분은 의미 있는 회귀 검사, 타입 검사와 UI 빌드를 통과한다. 실제 Windows 호스트를 실행하지 않은 경우 그 한계를 보고한다.
