## Windows 설치본

설치 경로와 데이터 경로에 공백을 넣고 설치했습니다. Git·개발용 Bun·Rust 경로를 PATH에서 제외하고, 빌드 폴더를 지정하는 환경변수 없이 실행했습니다.

- 설치된 payload 23,594개 파일의 해시가 manifest와 모두 일치했습니다.
- 빈 로컬 기억 저장소에 모델·한국어 사전·서버를 준비하고, 입력줄에서 작성한 기록을 저장했습니다.
- 입력줄의 자동 초점, 입력·질문 전환, 말풍선에서 상세 결과 열기와 원문 조회·수정을 확인했습니다.
- 재실행 후 큰 창 없이 펫만 나타났고, 인증정보와 수정한 기억이 유지됐습니다.
- 중복 실행은 두 번째 프로세스가 종료되는 것을 확인했습니다.
- 자동 실행에 공백 경로가 올바르게 인용되어 등록됐습니다.
- 제거 후 DB·설정·인증정보 파일 5개의 해시가 그대로 유지됐고 자동 실행 등록은 제거됐습니다.

ONNX와 필수 CRT DLL 네 개가 실제로 설치된 앱 폴더에서 로드되는 것을 확인했습니다. 네이티브 릴리스 EXE의 import는 Windows 기본 DLL/UCRT이며, 개발용 빌드와 구분해 검사했습니다. 의존성의 테스트 이미지 스냅샷은 Windows 경로 길이 문제를 피하도록 배포에서 제외합니다.

## 재현과 범위

빌드는 [개발 안내](development.md)를 따릅니다. 설치·인증된 Codex CLI가 없으면 해당 실제 준비 검사도 건너뛰어집니다.

상세 로그와 생성된 테스트 데이터는 Git에 포함하지 않는 `.omx/e2e`에 보관합니다. 설치 파일은 `artifacts`에 별도로 보관하며, 소스 저장소에 실행 파일·인증 키·사용자 DB를 커밋하지 않습니다.

설치 파일은 코드 서명되지 않았습니다. 이번 검증은 개발 도구가 설치된 Windows 호스트에서 실행 경로를 격리한 검증이며, 새 Windows 가상머신 검증은 아닙니다. Linux ARM64 Bun 파일의 해시는 확인했지만 실제 ARM64 장비 실행은 검증하지 않았습니다.
