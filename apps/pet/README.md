# Bara System Pet

작은 데스크탑 펫을 통해 부담 없이 기억을 남기고 질문하는 바라 클라이언트입니다. **비개발자가 Windows 설치 파일 하나로 준비하고 사용할 수 있게** 만듭니다.

0.1.0에는 펫, 입력줄, 말풍선, 로컬·원격 설치와 AI 연결이 구현되어 있습니다. 실제 Windows 설치와 기억 저장·검색·수정·재실행·제거를 확인했습니다. 자세한 결과는 [검증 기록](docs/verification.md)과 [진행 상황](docs/status.md)을 확인하세요.

## 사용 경험

- 펫을 누르면 작은 입력줄이 열리고 바로 타이핑할 수 있습니다.
- 입력줄 왼쪽에서 입력과 질문을 전환하고 오른쪽 버튼으로 보냅니다.
- 펫을 다시 누르거나 입력창 바깥을 누르면 입력창이 닫히며, 작성하던 내용은 유지됩니다.
- 한 줄 메모를 남기는 데 태그나 분류 입력을 요구하지 않습니다.
- 저장 결과와 짧은 답은 말풍선으로 알립니다. 누르면 자세한 결과와 원문을 열고, 그대로 두면 말풍선이 접힙니다.
- 최근 답변은 말풍선이 사라진 뒤에도 다시 볼 수 있습니다.
- 로그인 시 자동 실행을 지원하고 메모리 서버 연결을 관리합니다.
- 답변용 로컬 AI와 정리용 AI를 연결할 수 있습니다.

## 설치에서 선택할 세 가지 경로

| 선택 | 내 PC | 메모리 서버 |
|---|---|---|
| 이 컴퓨터에 설치 | 펫과 메모리 서버 설치 | 내 PC에서 실행 |
| 내 외부 서버에 설치 | 펫 설치 | 이미 준비된 서버에 원격 설치 |
| 기존 바라에 연결 | 펫 설치 | 기존 서버와 데이터를 그대로 사용 |

설치 파일 사용자에게 개발 도구 설치, 저장소 복제, 터미널 명령 입력을 요구하지 않습니다. 외부 서버를 선택하면 서버 주소와 접속 자격은 필요하며, 클라우드 인스턴스 생성은 별도 작업입니다.
