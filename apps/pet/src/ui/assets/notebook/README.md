# Notebook materials

Generated with the built-in ImageGen tool on 2026-10-08 for the user-approved Bara Pet notebook popup design. The assets contain no UI text or controls; real DOM content is layered above them.

- `notebook-shell.png`: 1024 × 1536, transparent exterior, ivory paper, top silver double-wire binding, layered paperboard edge. Based on the approved in-chat notebook concept, with text, marks, controls and index tabs removed.
- `index-tab.png`: 1774 × 887, transparent exterior, blank neutral paper index tab with rounded exposed left edge and straight right edge. The UI tints this material for the four index menus.

Generation prompts:

> Preserve the front-facing vertical ivory notebook, oatmeal paperboard, layered rounded page edges and twelve silver-gray top double-wire loops. Remove all content, logos, dividers, controls and tabs. Use a true alpha-transparent exterior, narrow safe margins, a clean blank fibrous paper interior, and no baked checkerboard or background.

> Generate one front-facing horizontal blank off-white fibrous paper index tab, rounded left corners and straight right attachment edge, subtle grain and edge highlight, neutral material for code tinting. No words, symbols or notebook. True alpha transparency with a small safe margin and subtle shadow.

Source generation files are retained in the originating chat's generated_images folder. These workspace copies are the runtime source assets, copied by `scripts/ui-assets.ts` into the application bundle.
